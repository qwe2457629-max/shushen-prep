# 上傳前檢查

文件寫好、審過、排好版之後，送出前逐條走一遍。上傳通常要申請人本人登入操作，這份清單可以直接給他用。

## 一、上傳欄位對應表

先打開報名系統的上傳頁（或簡章的上傳說明），照畫面上的順序做一張表：

| # | 系統欄位名稱（照畫面抄） | 要放的檔案 | 格式／大小上限 | 實際大小 | 頁數 | 檢查 |
|---|---|---|---|---|---|---|
| 1 | 歷年成績單 | `成績單含名次.pdf` | PDF／5MB | 1.2MB | 3 | ☐ |
| 2 | 自傳 | `自傳.pdf` | PDF／5MB | 0.3MB | 2 | ☐ |
| 3 | 讀書計畫 | `讀書計畫.pdf` | PDF／5MB | 0.4MB | 3 | ☐ |
| 4 | 其他有利審查資料 | `其他有利審查資料.pdf` | PDF／5MB | 4.1MB | 7 | ☐ |
| 5 | 文字欄：個人簡歷（300 字） | `簡歷.txt` | 純文字 | — | 287 字 | ☐ |

- 每個欄位對一個檔，不要一個檔對兩個欄位，也不要漏欄位。
- 簡章規定「限一份 PDF」的，用 `merge_pdfs.py` 合併，順序照簡章列的繳交順序。
- 推薦信通常不在這張表裡（推薦人自己上傳），但要另外記推薦人的截止時間。

## 二、檔案

- [ ] **副檔名小寫** `.pdf`。有些系統認不得 `.PDF`。
- [ ] **大小**：單檔、總檔都在上限內。上限之外，也注意上傳工具本身的限制（瀏覽器、雲端硬碟同步、你用來代上傳的工具），有時比系統上限還小。
- [ ] **檔名**：簡章有規定命名就照規定。沒規定時，用「姓名_系所_項目」這種一看就懂的名字。有些系統對中文、空白、特殊符號的檔名處理不好，遇到上傳失敗先換成英數＋底線試。
- [ ] **測試檔不要用正式檔名。** 測試上傳時用 `TEST_請勿使用.pdf` 這種一看就知道的名字，免得最後送出的是測試版。測完記得刪掉或覆蓋。
- [ ] **沒有密碼**。加密的 PDF 審查端可能打不開。
- [ ] **頁首的系所名稱、組別是這一所的**。複製上一所的檔案最常忘記改。
- [ ] 每個 PDF 都從頭到尾看過一遍（轉成 PNG 看，或申請人自己打開看）。

## 三、書籤、超連結、順序

- [ ] 簡章寫「不得有書籤／超連結」的：用 `reorder_proofs.py`（預設就會移除）或 `merge_pdfs.py`（`"bookmarks": false, "strip_links": true`），確認腳本回報的**連結數、書籤數都是 0**。掃描檔通常沒有，但從網頁存的證明、官網截圖存成的 PDF、系統產生的成績單常常帶連結。
- [ ] 簡章寫「依個人資料表提及事項順序檢附」的：用 `render_form.py` 印出的 proof 順序，直接餵給 `reorder_proofs.py --order`。
- [ ] 個人資料表上有列、但沒有證明的項目，不要放進佐證順序；最好表上也不要列，真的要列就在證明欄寫「無證明」。
- [ ] 合併總檔的目錄頁碼對得上實際頁序（轉 PNG 抽看一兩項）。目錄超過一頁時 `merge_pdfs.py` 會自動重算頁碼，但目錄一頁最好讀，太長就把項目合併。

## 四、報名系統的文字欄

很多報名系統有直接打字的欄位（簡歷、學歷、自傳摘要、研究興趣）。

- [ ] 先寫成 `.txt`，跑一次：

```bash
python3 scripts/check_text.py 簡歷.txt --limit 300 --count nospace --encoding cp950
```

- [ ] 字數算法照系統的：有的算含空白、有的算去空白、有的只算中文字。拿不準時用最嚴的算法。
- [ ] 能用 cp950（Big5）存。不能存的字貼進去會變問號或亂碼。常見的是罕用字、簡體字、特殊符號。
- [ ] 處理掉危險字元：特殊破折號（— – ―）、emoji、零寬字元、不換行空白（NBSP）、tab、從 Word 複製帶來的 `\r`。`check_text.py` 會列出位置和建議替代字。
- [ ] 貼進系統後按「預覽」或「儲存」看一次，確認沒有亂碼、換行沒有跑掉。
- [ ] 學校、系所名稱照官方全名（例如「OO大學／XX學系」），跟成績單一致。

## 五、時間

- [ ] 報名、繳費、上傳、推薦信的截止時間各是什麼，**寫到分鐘**。常常不是同一天，上傳截止也可能比報名晚。
- [ ] 不要卡最後一小時上傳。系統尖峰時很慢，掃描檔大的會逾時。建議提早一天。
- [ ] 推薦人的截止時間比你的早還是晚？推薦人要自己進系統上傳的，提早一週提醒。
- [ ] 推薦信是推薦人的意見，由推薦人自己寫、自己上傳。推薦人需要資料時，給他一份事實清單（做過什麼、哪些有證明、申請哪些系所），不要代寫推薦信。
- [ ] 面試日期有沒有撞期？（看 `templates/deadline_tracker.md`）撞期要早點讓申請人決定取捨。
- [ ] 民國年換算對了嗎？（民國年＋1911＝西元年）

## 六、送出

- [ ] 送出前，申請人本人把每個 PDF 從頭看過，確認內容都是真的、都是他願意在口試講的。
- [ ] 很多系統送出後就不能改。確定了再按。
- [ ] 送出後，從系統下載或預覽回來看一次，確認上傳的是對的檔。
- [ ] 截圖或存下送出成功的頁面、收件確認信。

## 排版的坑

用 `scripts/md2pdf.py`、`render_form.py` 時大多已經處理好；自己手寫 LaTeX 或用其他工具時要注意。

| 坑 | 症狀 | 處理 |
|---|---|---|
| xeCJK 把半形區間號「–」排成全形長槓 | 「2024–2025」中間變成一條很長的線 | `md2pdf.py` 自動處理；手寫 LaTeX 時把區間號包起來或換成連字號 |
| 直引號 `"` `'` | PDF 上的引號方向不對 | `md2pdf.py` 自動轉成彎引號 |
| 頁首用破折號分隔 | 頁首的「—」被排成全形，看起來很空 | 頁首用「｜」分隔，例如 `OO大學 永續管理研究所｜自傳` |
| LaTeX 特殊字元 | `& % $ # _ { } ~ ^ \` 讓編譯失敗或字不見 | `md2pdf.py` 自動跳脫 |
| 掃描檔太大 | 合併檔超過上限 | `merge_pdfs.py` 的 `compress: true`；或請申請人用約 200–250 dpi 重掃，文字仍然清楚 |
| 透明背景的 PNG | `pdf_pages.py` 用 macOS `sips` 轉出的圖，在某些看圖程式顯示成黑底 | 加 `--white-bg` 貼白底（需要 Pillow）；用 Read 看圖不受影響 |
| 簡章抽字是亂碼 | 用 CID 字型的 PDF 抽出空白或怪字 | `pdf_pages.py --text` 會提示，改看 PNG |
| 限一頁的文件超頁 | 自傳、個人資料表多出幾行 | 先刪內容，最後才用 `--compact` |
| 表格被切到下一頁 | 個人資料表跨頁 | 減少條目或縮短每條，`render_form.py --max-pages 1` 會擋 |
| 頁數對但版面怪 | 孤行、標題落在頁底、字擠在一起 | 每份都用 `pdf_pages.py` 轉 PNG 看過 |
| 佐證順序錯 | 跟個人資料表對不上 | 用 `render_form.py` 印出的順序，不要手排 |
| 書籤或連結殘留 | 簡章禁止卻還有 | 看腳本回報的連結數、書籤數 |

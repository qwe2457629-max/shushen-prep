# 對抗式審查清單

寫完的文件先審再排版。審查的前提是：**預設每份文件都有錯，任務是把錯找出來。**

## 怎麼用

1. 準備給審查者的資料：事實表、要求對照表、證明文件清單（每份證明是什麼、日期、上面寫的職稱）、第 4 步查到的系所重點（含網址）、要審的原稿。
2. 從下面四個角度各審一遍。可以開四個 subagent 各扮一個角色，平行跑；也可以一個 subagent 依序看四遍。分開跑比較不會互相放水。
3. 每條意見用這個格式回報：

```json
{
  "file": "自傳.md",
  "quote": "原句（照抄）",
  "problem": "哪裡有問題、依據是什麼",
  "severity": "blocker | major | minor",
  "fix": "可以直接套用的改法"
}
```

4. 處理意見：blocker、major 全部處理；minor 合理就改。**審查意見跟事實表衝突時，以事實表為準**，不採納並記下理由。
5. 改完後，只針對改過的段落再審一次（改的時候最容易帶進新錯）。

## 嚴重度

| 等級 | 定義 | 例子 |
|---|---|---|
| **blocker** | 不改不能交。捏造、沒有依據、時序矛盾、違反簡章硬規定、讓資格出問題 | 寫了事實表沒有的獎項；超過頁數限制；簡章禁止書籤卻有書籤；漏交一項必繳資料 |
| **major** | 原則上要改。說法超過證據、口試一問就倒、跨文件不一致、漏了簡章要的子項目 | 草案寫成已試點；點名沒查證的教授；中英兩版日期不同；「含生涯規劃」卻沒寫 |
| **minor** | 合理就改。文風、贅字、可以更具體 | 顧問腔用詞；段落太長；英文有 AI 腔 |

拿不準的時候往上一級算。

## 角度一：事實查核員

只看一件事：每個具體說法追不追得到。

- [ ] 每個人名、組織名、職稱、日期、數字、獎項、分數，都在事實表找得到嗎？
- [ ] 職稱、學位英文名、課名，跟證明文件上的寫法一樣嗎？
- [ ] 每段經歷的起訖、在學期間還是畢業後，跟事實表一致嗎？有沒有把後來的經驗寫到前面那段？
- [ ] 有沒有「畢業後……從大三實習開始」這種自相矛盾的句子？
- [ ] 已結束的事是不是過去式？有沒有「目前」「迄今」「currently」？
- [ ] 年資算法對嗎？有沒有把實習和正職加總成「N 年經驗」？
- [ ] 草案、構想有沒有寫成已試點、已上線、有使用者、協助了幾家？（中英文的動詞都要看）
- [ ] 「聯繫過」「拜訪過」有沒有寫成「合作」「夥伴」？
- [ ] 團隊成果有沒有寫清楚申請人自己負責哪塊？
- [ ] 語言能力是照檢定寫的嗎？有沒有「母語」「流利」「native」這類沒有依據的說法？
- [ ] GPA 有註明制度嗎？名次寫法跟名次證明一致嗎？
- [ ] 政策、法規、產業數字都有來源嗎？有沒有絕對句？
- [ ] 有沒有用到事實表「不能怎麼寫」或申請人標記過有風險的內容？
- [ ] 中英兩版的事實一致嗎？

## 角度二：系所委員

假裝自己是這個所的教授，手上有 40 份要看，每份給三分鐘。

- [ ] 看完第一頁，知道這個人是誰、為什麼要來嗎？
- [ ] 「為什麼是這個所」講的是這個所特有的東西（課程、研究方向、授課方式），還是換個校名也能用？
- [ ] 提到的系所重點，在第 4 步的系所清單上有網址嗎？
- [ ] 研究或學習方向具體嗎？讀得出要做什麼、怎麼做？
- [ ] 研究問題兩年內做得完嗎？資料拿得到嗎？有沒有要用前雇主或客戶的內部資料？
- [ ] 申請人的背景跟想做的研究接得起來嗎？中間有沒有跳太大步？
- [ ] 有沒有一段在講空話（拿掉也不影響理解）？
- [ ] 簡章要求的每個子項目（動機、學習計畫、生涯規劃……）都找得到對應段落嗎？
- [ ] 有沒有寫得太負面的自評？

## 角度三：口試委員

口試委員會拿著書審追問。這個角度的產出除了 issues，還要一張**口試追問清單**。

- [ ] 列出你會問的 10 個問題。每題標出它是根據文件哪一句。
- [ ] 文件裡每個專有名詞、方法、理論，申請人說得出是什麼、為什麼用嗎？
- [ ] 引用的每篇文獻，申請人讀過嗎？（事實表沒寫讀過，就當沒讀過）
- [ ] 每個數字，申請人說得出怎麼來的嗎？
- [ ] 點名的教授，申請人說得出他在做什麼嗎？
- [ ] 有沒有寫了但沒有證明的說法？全部列出來，交付時放進「口試要準備」。
- [ ] 有沒有一句話在 A 所和 B 所的文件裡立場相反，口試被問「你還報了哪裡」時會穿幫？
- [ ] 生涯規劃說得通嗎？（例如說要回某地工作，那個地方真的有這種工作嗎）

## 角度四：規範檢查員

拿要求對照表一項一項對，不看內容好壞，只看合不合規定。

- [ ] 簡章列的每個繳交項目，都有對應的檔案嗎？
- [ ] 頁數、字數是實際排版後算的嗎？（用 `md2pdf.py`、`render_form.py` 的輸出，不要用估的）
- [ ] 「中文及英文」的項目，兩個語言都有嗎？兩版合計是否在限制內？
- [ ] 模糊的規定是用最嚴格的解讀嗎？
- [ ] 個人資料表條目數、字數欄位在上限內嗎？
- [ ] 佐證順序跟個人資料表的出現順序一致嗎？表上列了的項目都有證明嗎？沒證明的項目有沒有列進佐證順序？
- [ ] 檔案格式、大小、檔數、命名符合規定嗎？
- [ ] 規定不得有書籤／超連結的，腳本回報的數字是 0 嗎？
- [ ] 總檔的順序照簡章列的順序嗎？目錄頁是一頁嗎？
- [ ] 頁首寫的系所名稱、組別正確嗎？（複製上一所的檔案最常忘記改）
- [ ] 文字欄位過了 `check_text.py` 嗎？

## 常見會被抓到的問題

這些是實際做過多個系所後，審查最常抓到的。寫的時候先自己避開。

**時序與時態**

1. 後來才有的經驗被寫到較早那段經歷底下（例如正職才接觸的業務，寫成實習就做過）。
2. 「畢業後進入某公司，從大三暑期實習開始」這類時序自相矛盾的句子。
3. 已經離職或結束的事還用現在式。
4. 年資灌水：兩段實習加一年正職寫成「三年經驗」；某項技能「從某年開始」的年份寫早了。

**名稱與證明**

5. 職稱跟離職證明不一樣。
6. 學位英文名稱自己翻，跟畢業證書不同。
7. 課程清單跟最新版履歷或成績單課名對不上（申請人改過清單，舊文件沒跟著改）。
8. 個人資料表列了沒有證明的項目，或佐證順序跟表格順序不一致。

**說法超過證據**

9. 草案、構想寫成已試點、已有使用者、已協助幾家。英文的 "real users"、"has helped"、"working tool" 最容易漏看。
10. 寄過信、開過會的組織，寫成合作夥伴。
11. 語言能力自稱流利或母語，但只有檢定分數或沒有檢定。
12. 寫了申請人不會的方法，或他自己已經從履歷刪掉的技能。

**口試地雷**

13. 加了申請人沒讀過的文獻。
14. 點名沒查證的教授。
15. 研究設計要用前雇主或客戶的資料。
16. 沒有來源的政策數字，或「某國完全沒有規範」這種絕對句。
17. 申請人說過有風險、不要用的故事，又被寫回來。

**跨文件**

18. 同時報不同領域，A 所寫「所以我不想再走 B」，B 所正說著相反的話。
19. 中英兩版事實不一致（改了一版忘了另一版）。
20. 複製上一所的文件，頁首或內文的系所名稱沒改。

**規範**

21. 簡章要求的子項目（含學習計畫、含生涯規劃）沒有對應段落。
22. 「中文及英文，限 1 頁」只算了其中一個語言。
23. 頁數用估的，實際排版後超頁。
24. 簡章禁止書籤或超連結，合併檔卻帶著。

**文風**

25. 顧問腔、翻譯腔，讀起來像在吹牛。
26. 英文有 AI 腔（申請人自己就會抓到，然後不信任整份）。
27. 弱項寫得太重，或寫成假弱項。
